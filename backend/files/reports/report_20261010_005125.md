## Why it matters (beginner notes)
- **Brute Force**: Attackers try many passwords until one works. Many failures from one address is a classic sign.
- **Path Traversal**: '../' tricks try to escape the website folder and read private files such as /etc/passwd.
- **Recon Scan**: Before attacking, intruders often scan for well-known pages (like WordPress logins) to find weak spots.
- **Blocked Connection**: Outsiders knocking on SSH (port 22) are looking for a remote way in; the firewall stopped it.
- **Suspicious Process**: Word launching PowerShell is a common sign of a malicious macro. This is the most worrying item because it is INSIDE the network.
- **Privilege Escalation Attempt**: Asking for admin rights right after odd activity can mean an account is being abused.
- **Rate Limit Abuse**: Hammering a login form is often automated credential stuffing (reusing leaked passwords).

## Recommended actions
1. Verify that user alex routinely logs in from IP address 192.0.2.10.
2. Ensure multi-factor authentication (MFA) is enabled for user alex to add a layer of defense beyond passwords.
3. Continue standard baseline monitoring on auth-service for any anomalous login spikes.
